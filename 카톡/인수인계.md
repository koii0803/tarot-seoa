## 0. 제일 중요한 것 — 이 폴더는 혼자 산다

`카톡/` 은 위 폴더(스레드 타로봇)를 **한 줄도 안 본다.**
전에는 `타로엔진·조립·분류·풀이·그림올리기` 를 그대로 불러 썼는데,
그러면 스레드를 고칠 때 카톡이 같이 부서진다. 그래서 전부 이 폴더로 복사했다.

| 카톡 | 스레드 원본 |
|---|---|
| `엔진.py` | `타로엔진.py` (+ 손님이 뽑은 카드 지정 인자 추가) |
| `부르기.py` | `풀이.py` (+ 말투·줄수만 카톡 것으로) |
| `조립.py` `분류.py` | 그대로 |
| `그림.py` | `그림올리기.py` |
| `말투.py` `말종류.py` | **카톡에만 있다** |

**고칠 때 위 폴더 파일을 건드리지 마라.** 여기 것만 고친다.

## 3. 흐름

```
손님 첫 마디
   └ 껍데기("ㅎㅇ" "안녕")  → 왔어 / 뭐가 궁금한지 한 줄만 적어줘
   └ 고민 한 줄            → 카드 누가 뽑을까  [내가 뽑을게] [니가 뽑아줘]
                                  │
        ┌─────────────────────────┴─────────────────────────┐
     [직접 라인]                                        [맡김 라인]
   사이트 주소를 준다                                기계가 바로 뽑는다
   손님이 이름 적어 옴 → 그 카드로 푼다
        └─────────────────────────┬─────────────────────────┘
                                  │
                      **카드 한 장 = 주제 하나 = 무제한 대화**
                      손님이 뭘 더 물어도 그 카드로 간다. 10턴이든 20턴이든
```

**라인은 한 번 정해지면 그 상담 내내 유지된다.** 기록의 `라인` 칸에 박힌다.

## 4. 못 박은 것 (전부 실측으로 잡은 것)

| 규칙 | 왜 |
|---|---|
| **되묻지 않는다** | 팔자오빠에서 "손님이 적은 걸 다시 묻기" 가 일주일에 7번 났다. 한 손님은 세 번 같은 말을 했는데 세 번 다 다시 물었다. 그 손님은 안 돌아온다. 그래서 새 주제면 묻지 말고 바로 뽑고, **되돌릴 버튼만** 단다 |
| **한 마디마다 새로 뽑지 않는다** | 전에는 한 상담에 카드가 스무 장씩 나왔다. 카드가 의미를 잃는다 |
| **답하기 전에 무거운 일을 하지 않는다** | 답 내보내기 전에 분류가 하이쿠를 불러서 즉답이 **11.76초** 나왔다. 카카오 skill timeout 은 5초다 |
| **최소 5초는 채운다** | 조립은 0.04초라 그냥 보내면 기계라고 광고하는 꼴이다. 그래서 **모든 답을 콜백으로** 보낸다 |
| **검사 다섯 겹** | 사람글인가 · 막힌말 · 부호 · 줄수 · 말투 · check_output. 웹 채팅을 베꼈다가 두 겹이 빠져서 재료에 없는 상징을 지어냈다 |
| **걸리면 세 번 다시 시킨다** | 한 번 쓰고 버리면 조립글로 떨어진다. 실제로 좋은 답이 4줄이라는 이유로 버려졌다 |
| **법으로 막힌 말** | 봐준다·전문가·감정해·적중·정확·100%·1위·Top1·용하다·신기 있다 (표시광고법·PG 심사). `말투.막힌말` 에 있다 |
| **"네가" 가 아니라 "니가"** | 사장님 지시 |

## 5. 카카오가 정한 시간 (오픈빌더 화면 문구 그대로)

| | |
|---|---|
| 첫 답 | **skill timeout: 5sec** |

(폴백 블록 → `...` → Callback 설정).

## 7. 같은 걸 또 밟지 마라

| 함정 | 내용 |
|---|---|
| **서버가 여러 개 뜬다** | 윈도는 같은 포트에 여러 프로세스가 LISTEN 되고 **먼저 잡은 쪽이 받는다.** 옛 서버 3개가 떠 있어서 고친 코드가 안 먹는 줄 알았다. 띄우기 전에 `netstat -ano | findstr :8767` 로 전부 죽여라 |
| **8766 은 웹 채팅이 쓴다** | 카톡은 8767. 겹치면 카카오 요청이 웹 채팅으로 샌다 |
| **Git Bash 가 경로를 바꾼다** | `--길 /skill/abc` 를 넘기면 `C:/Program Files/Git/skill/abc` 로 바뀐다. **앞 슬래시 없이** `skill/abc` 로 넘겨라 |
| **클라우드플레어가 파이썬을 막는다** | 기본 User-Agent 로 부르면 403. 이름표를 붙여야 한다 |
| **Git Bash curl 은 한글을 CP949 로 보낸다** | 서버 잘못인 줄 알고 한참 헤맸다. 시험은 파이썬으로 UTF-8 보장해서 하라 |
| **봇테스트는 손님 번호가 고정이다** | 기록이 남아 있으면 갈림길을 건너뛴다. 기록을 비우고 시험해라 |
