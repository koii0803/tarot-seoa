## 3부 · 어그로 방식 여섯 가지 (반응 큰 순)

### ① 무료 OX 리딩 — 제일 강하다
```
hanareum_tarot   좋아요 288 · 댓글 571 · 리포스트 249
moonlight.sue    조회 1,800 · 댓글 65
i.m_yeontto      좋아요 55 · 댓글 106
bamtoltarot      좋아요 47 · 댓글 84 · 리포스트 46
```
**공식이 굳어 있다.**
1. **수량 제한** — "20명 정도" "딱 6명" "딱 한 분" "5명 마감되면 이 글 삭제할게"
2. **질문 형식 제한** — "O/X로 답할 수 있는 질문만"
3. **복채 = 스하리** (스레드+하트+리포스트). 돈이 아니라 노출을 받는다
4. **안 보는 것 미리 못 박기** — "건강·임신·사업운은 안 봐"
5. 끝나면 "마감합니다" 글을 따로 올려 한 번 더 노출

### ② 개업·사연 서사

## 4부 · 프로필(이름·소개) 공식

이름 칸에 **전부 때려 박는다.**
```
타로✨봄샘타로✨[보이스톡 타로 / 재회운•연락운•사업운]
루 타로♥️| 1:1심화상담 | 카톡타로 | 전화타로 | 타로맛집1등♥️
타로피아🕊️[타로상담 • 재회 • 연애 • 연락운 전문 / 1:1 맞춤 리딩 & 현실 솔루션]
```
검색어를 이름에 넣는 것이다. `재회`가 거의 전부에 들어 있다.

소개에 쓰는 말 (**우리는 대부분 못 쓴다**)
- `적중률 96.0%` `적중률 만족도 🔝` ← 우리 금지어
- `재방문율 98%` `누적 상담 15,000회` `후기 1,000건 돌파`
- `무당이 추천한 타로` `무당쌤들도 찾는 타로 맛집`
- `당일 예약` `새벽 2시까지` `24시` ← 시간 경쟁
- 끝은 항상 `⬇️ 프로필 링크` 또는 카카오 오픈채팅

## 5부 · 빈자리 (우리가 들어갈 곳)

1. **전부 사람이 1:1로 봐준다.** 수량 제한이 있고 마감한다. **자동으로 무제한인 곳이 없다**
2. **전부 카카오로 빼낸다.** 스레드 안에서 끝나는 곳이 없다
3. **재회에 몰려 있다.** 시험·일·돈은 간판에만 있고 실제로 다루는 곳이 적다
4. **사주 결합이 거의 없다.** `unsebom_` `my_topaz_910` `haeyundam` 정도인데 타로와 따로 논다
5. **그림을 안 쓴다.** 대부분 글자만 올린다. 우리는 앞면 22장이 있다
6. **적중률 싸움에 이미 손님이 질렸다** (3부 ③④). **"안 맞힌다"가 오히려 차별점이 된다**

## 6부 · 그래서 서아 계정은 이렇게 간다 (제안)

| | 저쪽 | 서아 |
|---|---|---|
| 수량 | "20명만" 마감 | **제한 없음.** 기계라 24시간 |
| 복채 | 스하리 요구 | **안 받는다** |
| 답 | O/X 단정 | 카드 + 되물음 (단정 금지) |
| 끝 | 카톡으로 빼냄 | **스레드 안에서 끝남.** 더 깊은 건 프로필 |
| 그림 | 없음 | **뒷면 답글 → 사이트에서 앞면 뒤집기** |
| 간판 | 적중률·재방문율 | **"점치는 게 아니라 같이 보는 거야"** |

첫 글 방향 세 개 (3부에서 나온 것)
1. **개업 서사** — 왜 시작했나. ②가 제일 세다
2. **무료 리딩** — 단 수량 제한 없이. 그게 우리만 가능한 것
3. **업계 이야기** — ④의 "대본집" 얘기는 손님도 아는 얘기다. 조심해서 쓰면 먹힌다

⚠️ ③ 저격은 잘 퍼지지만 하지 않는다. 남 이름 대는 순간 싸움이 되고 우리 문구 규칙에도 어긋난다.
